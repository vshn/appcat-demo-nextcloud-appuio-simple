# Example Deployment of [VSHNNextcloud](https://products.vshn.ch/appcat/nextcloud.html)

An example how to deploy VSHNNextcloud with a [Github Actions
pipeline](.github/workflows) to [APPUiO](https://www.appuio.ch).

The pipeline was generated with [AppFlow](https://github.com/vshn/appflow-demo).\
The configuration of the VSHNNextcloud can be seen in [nextcloud.yaml](helm/templates/nextcloud.yaml)[^1].

[^1]: [Documentation reference for VSHNNextcloud](https://docs.appcat.ch/vshn-managed/nextcloud/index.html)
